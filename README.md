# Fox's Tinker Traits（匠魂强化与词条）

一个面向 Minecraft 1.12.2 的 Forge 模组，为 **匠魂（Tinkers' Construct）** 与 **匠魂盔甲（Construct's Armory）**
补充一组可配置的自定义词条（强化）。所有词条的最大等级、每级效果、强化槽消耗与强化物均可在配置文件中调整。

## 词条一览

| 词条 | ID | 类型 | 说明 |
|------|----|------|------|
| 半神 | `demigod` | 盔甲 | 按比例削减受到的生命值损失；可选是否同样削减回血。 |
| 芝诺的乌龟 | `turtle` | 盔甲 | 需要半神前置。限制单次掉血不超过当前生命值的一定比例。 |
| 落花之情 | `blossom` | 盔甲 | 未损坏的盔甲按耐久上限提供定值减伤，多件叠加。 |
| 残命之契 | `lifecontract` | 盔甲 | 限制玩家当前生命值（满级时最大为 1），并按等级提供伤害减免。 |
| 防毒面具 | `gasmask` | 头盔 | 每级有一定概率取消负面效果的施加。 |
| 超级防毒面具 | `supergasmask` | 头盔 | 100% 取消负面效果的施加，由满级防毒面具升级而来。 |
| 反击 | `counter` | 工具 | 受到攻击时，手持的工具有几率自动反击攻击者。 |
| 自动攻击 | `autoattack` | 工具 | 按住左键时，按工具攻击速度自动攻击准星目标；主副手均可。 |
| 诸武精通 | `weaponmaster` | 远程工具 | 发射的匠魂投射物命中时，每级额外获得一定近战攻击力作为远程伤害加成。 |
| 多重打击 | `multistrike` | 投射物 | 命中后滞留并连续造成多次伤害，随后继续飞行；等级决定穿透目标数、滞留时间与额外伤害次数。 |

## 配置文件

首次启动后生成 `config/foxtinkertraits.cfg`，按词条分为独立分类，每个分类下可配置：

- `maxLevel`：最大强化等级
- `perLevel` / 相应倍率：每级效果
- `freeModifiers`：每级消耗的强化槽数量
- `items`：强化所需的物品（支持多个，逗号或分号分隔，格式 `modid:item` 或 `modid:item:meta`）

部分词条有专属选项，例如落花之情与残命之契的减伤时机、乌龟的生命阈值、半神的回血削减开关等。

## 技术要点

- **Forge CoreMod**：通过 `IFMLLoadingPlugin` 注册 ASM `IClassTransformer`，改写匠魂投射物相关字节码，
  实现诸武精通（远程伤害加成）与多重打击（滞留、穿透、多次结算）等原生词条体系难以实现的效果。
- **Mixin**：注入原版类，实现半神/乌龟/残命之契的生命值修改与减伤时机控制。
- **副手自动攻击**：仿 RLCombat 引入玩家能力（Capability）记录副手攻击冷却，
  使副手工具能正确吃到自身的攻速与玩家来源（急迫、饰品等）的攻速加成。
